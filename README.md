# LARP Wallet

A free, installable novelty wallet simulator built as a static PWA for GitHub Pages.

## What it does
- 24 starter cards with photo and gradient artwork
- Add, delete, duplicate and reorder cards
- Customize title, subtitle, footer, last four digits, colors, category, image URL and gradient
- Wallet-level dark/light/system themes, card spacing, corners, stack scale and photo overlay
- Search and category filters
- Persistent local storage
- JSON import/export
- Add to iPhone Home Screen as a standalone PWA
- Mandatory **SIMULATION** labeling

## What it intentionally does not do
This project has no real money, bank connection, payment function, NFC, credential storage, transaction history, receipts, statements, barcodes, QR credentials or real issuer integration. It is a visual prop for content, demos and roleplay only.

It is not affiliated with Apple, any bank, card network, issuer, airline, hotel, transit operator or the original zlarp service.

## Photo backgrounds
Starter photo backgrounds load remotely from Unsplash image URLs. You can replace any image URL in Backstage. If you publish or redistribute this project, follow the image provider's terms and attribution requirements where applicable.

## Install on iPhone
1. Open the GitHub Pages URL in Safari.
2. Tap Share.
3. Tap **Add to Home Screen**.
4. Launch it from the new icon.

## GitHub Pages
This repository is intentionally plain HTML/CSS/JS so it can be served directly from the `main` branch root using GitHub Pages.
